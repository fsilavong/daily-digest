# Teaching Language Models to Think in Code

- Source: https://arxiv.org/abs/2605.07237
- Title: Teaching Language Models to Think in Code

## Evidence

> Tool-integrated reasoning (TIR) has emerged as a dominant paradigm for mathematical problem solving in language models, combining natural language (NL) reasoning with code execution. However, this interleaved setup has three key limitations: code often acts as a post-hoc verifier, intermediate NL computations are error-prone, and NL and code play overlapping rather than clearly distinct roles. We propose ThinC (Thinking in Code), a framework in which code itself serves as the reasoner rather than as a tool invoked by NL. ... We distill 12.2k code-centric trajectories from a teacher model and train ThinC-1.7B and ThinC-4B ... ThinC-4B consistently outperforms every TIR baseline on five competition-level math benchmarks and even surpasses the much larger Qwen3-235B-A22B-Thinking. ... 99.2% of its final answers are grounded in interpreter output...
