# Rollout Cards: A Reproducibility Standard for Agent Research

- Source: https://arxiv.org/abs/2605.12131
- Title: Rollout Cards: A Reproducibility Standard for Agent Research
- Published: 2026-05-13

## Evidence

> Reproducibility problems that have long affected machine learning and reinforcement learning are now surfacing in agent research: papers compare systems by reported scores while leaving the rollout records behind those scores difficult to inspect.
>
> ... none report how many runs failed, errored, or were skipped alongside headline scores.
>
> We treat rollout records, not reported scores, as the unit of reproducibility for agent research. We introduce rollout cards: publication bundles that preserve the rollout record and declare the views, reporting rules, and drops manifests behind reported scores.
>
> ... changing only the reporting rule can change reported scores by 20.9 absolute percentage points and, in some cases, invert rankings of frontier models.
