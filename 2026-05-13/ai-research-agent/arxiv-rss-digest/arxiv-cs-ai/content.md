# arXiv cs.AI digest for 2026-05-13

## Agent adaptation and planning

- **OLIVIA: Online Learning via Inference-time Action Adaptation for Decision Making in LLM ReAct Agents** — OLIVIA targets deployment-time adaptation for ReAct-style agents by modeling the final action-selection layer as a contextual linear bandit over candidate actions, using frozen hidden states as decision contexts. The abstract emphasizes that this makes adaptation explicit at the action layer, preserves the underlying reasoning process, and provides uncertainty estimates with lightweight online updates. It reports improvements over static ReAct and prompt-based inference-time baselines on four benchmarks. [1](./citations/1.md)

- **PIVOT: Bridging Planning and Execution in LLM Agents via Trajectory Refinement** — PIVOT addresses plan-execution mismatch by treating trajectories as optimizable objects refined through environment interaction. Its four stages are PLAN, INSPECT, EVOLVE, and VERIFY, with structured losses and textual gradients encoding discrepancies between plans and execution. The abstract claims state-of-the-art results on DeepPlanning and GAIA, up to 94% relative improvement in constraint satisfaction with HITL feedback, and 3x to 5x fewer tokens than competing refinement methods. [2](./citations/2.md)

## Memory, retrieval, and evaluation infrastructure

- **Rethinking Evaluation for LLM Hallucination Detection: A Desiderata, A New RAG-based Benchmark, New Insights** — This paper argues that current hallucination-detection benchmarks miss key properties, especially long-context RAG-style grounded settings and realistic label noise. It introduces T RIVIA+, a new RAG-based benchmark with rigorous human annotation, the longest context in the literature according to the abstract, and four noisy-label sets with both sample-dependent and sample-independent schemes. The reported experiments suggest substantial headroom for existing detectors, competitive performance from a basic LLM-as-a-Judge baseline, and degraded performance under label noise. [3](./citations/3.md)

- **SAGE: A Self-Evolving Agentic Graph-Memory Engine for Structure-Aware Associative Memory** — SAGE reframes graph memory as a dynamic long-term memory substrate rather than static retrieval middleware. The system pairs a memory writer that builds structured graph memory from interaction histories with a Graph Foundation Model-based reader that retrieves and feeds back to the writer. The abstract reports gains across multi-hop QA, open-domain retrieval, review QA, and long-term agent-memory benchmarks, including best average rank on multi-hop QA after two self-evolution rounds and 82.5/91.6 Recall@2/5 on NQ in zero-shot open-domain transfer. [4](./citations/4.md)

- **Rollout Cards: A Reproducibility Standard for Agent Research** — The paper argues that agent research should treat rollout records, not reported scores, as the reproducibility unit. It reports an audit of 50 training and evaluation repositories in which none disclosed failed, errored, or skipped runs alongside headline scores, and it motivates rollout cards as publication bundles that preserve rollout records and the reporting rules behind them. The abstract says changing only the reporting rule can shift scores by 20.9 absolute percentage points and even invert frontier-model rankings in some settings. [5](./citations/5.md)

- **An Executable Benchmarking Suite for Tool-Using Agents** — This is a benchmarking/infrastructure paper rather than a new agent policy. It presents a shared evidence-admission contract spanning WebArena Verified, a SWE-Gym slice with SWE-bench-compatible verification, and MiniWoB++, using common adapters, manifests, schemas, replay/freeze policy, declared drivers, and reporting pipelines. The abstract highlights admitted evidence such as latency, invalid actions, patch-generation cost, verifier metadata, replay bindings, and provenance. [8](./citations/8.md)

## Monitoring, memory, and session state

- **Classifier Context Rot: Monitor Performance Degrades with Context Length** — The paper studies monitoring coding agents for dangerous behavior when transcripts exceed 500K tokens. It reports that frontier LLM classifiers miss subtle dangerous actions 2x to 30x more often when those actions occur after 800K tokens of benign activity than when they occur in isolation, and that periodic reminders can partially mitigate the issue. The abstract warns that benchmarks lacking long-context degradation may overestimate monitor performance. [6](./citations/6.md)

- **Beyond Similarity Search: Tenure and the Case for Structured Belief State in LLM Memory** — Tenure frames cross-session memory as state management rather than search. It proposes a local-first proxy with a typed belief store, epistemic status, versioned supersession, and scope isolation, then injects curated context into every session through precision-first retrieval. The abstract’s controlled evaluation reports mean precision 1.0 for alias-weighted BM25 versus 0.12 for cosine similarity over dense embeddings on 72 retrieval cases, and notes drift issues for vector retrieval under topic drift. [9](./citations/9.md)

## Safety, reward, and red-teaming

- **Reward Hacking in Rubric-Based Reinforcement Learning** — This work studies reward hacking when policies are optimized against a training verifier but judged against a panel of three frontier judges. It separates verifier failure from rubric-design limitations, reports that weak verifiers produce proxy-reward gains that do not transfer to reference verifiers, and says exploitation grows over training in recurring failure modes such as partial satisfaction of compound criteria and imprecise topical matching. The abstract concludes that stronger verification reduces hacking but does not guarantee broader quality gains. [7](./citations/7.md)

- **Proteus: A Self-Evolving Red Team for Agent Skill Ecosystems** — Proteus models skill deployment risk as adaptive leakage, where an attacker iteratively revises a skill using audit and runtime feedback until it passes audit and produces verified runtime harm. The abstract describes a grey-box, self-evolving red-team framework over a formalized five-axis skill-attack space, with a unified audit-sandbox-oracle pipeline and cross-round mutation. It reports 40–90% ASR@5 across eight phase-1 cells and 438 jointly bypassing and lethal variants in phase 2, indicating substantial residual risk under adaptive attack. [10](./citations/10.md)
