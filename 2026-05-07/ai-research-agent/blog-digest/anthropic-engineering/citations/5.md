# Quantifying infrastructure noise in agentic coding evals

- Source: https://www.anthropic.com/engineering/infrastructure-noise
- Title: Quantifying infrastructure noise in agentic coding evals

## Evidence

> In internal experiments, the gap between the most- and least-resourced setups on Terminal-Bench 2.0 was 6 percentage points (p < 0.01).
>
> We ran Terminal-Bench 2.0 across six resource configurations ... same Claude model, same harness, same task set.
>
> success rates increased with resource headroom ... infra error rates dropping monotonically ... from 5.8% at strict enforcement to 0.5% when uncapped.
>
> We also tested ... SWE-bench ... across 227 problems with 10 samples each.
>
> We recommend that evals specify both parameters per task, not a single pinned value.
