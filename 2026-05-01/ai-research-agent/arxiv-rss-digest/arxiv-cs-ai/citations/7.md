# Reinforced Agent: Inference-Time Feedback for Tool-Calling Agents

- Source: https://arxiv.org/abs/2604.27233
- Title: Reinforced Agent: Inference-Time Feedback for Tool-Calling Agents

## Evidence

> We move evaluation into the execution loop at inference time: a specialized reviewer agent evaluates provisional tool calls prior to execution, shifting the paradigm from post-hoc recovery to proactive evaluation and error mitigation. ... To quantify this tradeoff, we introduce Helpfulness-Harmfulness metrics: helpfulness measures the percentage of base agent errors that feedback corrects; harmfulness measures the percentage of correct responses that feedback degrades. We evaluate our approach on BFCL (single-turn) and Tau2-Bench (multi-turn stateful scenarios), achieving +5.5% on irrelevance detection and +7.1% on multi-turn tasks.
