# Claude Code auto mode: a safer way to skip permissions

- Source: https://www.anthropic.com/engineering/claude-code-auto-mode
- Title: Claude Code auto mode: a safer way to skip permissions

## Evidence

> Auto mode aims to reduce approval fatigue by replacing manual permission prompts with model-based safety classifiers.

> Uses a two-layer system: a prompt-injection probe on inputs and a transcript classifier on outputs; the classifier runs a fast stage-1 filter and a more expensive stage-2 reasoning pass only when needed.

> The design lets many routine actions proceed without prompts while still blocking dangerous actions like credential exploration, exfiltration, destructive deletion, and safety-check bypasses.

> The system depends on classifier quality and policy tuning; it intentionally strips Claude’s own messages/tool outputs from the classifier context, and broad interpreter escapes are removed on entering auto mode.

> Provides a middle ground between high-friction manual approval and unsafe fully unchecked execution, improving autonomy without abandoning guardrails.
