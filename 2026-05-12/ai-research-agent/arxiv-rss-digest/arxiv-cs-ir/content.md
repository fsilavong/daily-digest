# arXiv cs.IR digest for 2026-05-12

## Cross-platform personalization via LLM agents

- **LLM Agents Enable User-Governed Personalization Beyond Platform Boundaries** argues that personalization is currently platform-centric, because services only see fragmented user behavior, while competitive incentives, legal constraints, privacy concerns, and epistemic limits prevent any single platform from building a complete user picture [1](./citations/1.md).
- The paper's central proposal is **user-governed personalization**: only the user can integrate cross-platform and offline contexts, and LLM agents make that integration feasible by reasoning over heterogeneous personal data and turning it into actionable personalization capabilities [1](./citations/1.md).
- It reports proof-of-concept evidence that users with cross-platform data exports and an off-the-shelf LLM agent can outperform single-platform personalization baselines [1](./citations/1.md).
- The abstract frames the work as an agenda-setting paper and closes by outlining a research agenda for scalable user-governed personalization systems [1](./citations/1.md).
