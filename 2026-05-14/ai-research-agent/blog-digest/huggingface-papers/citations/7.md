# PresentAgent-2: Towards Generalist Multimodal Presentation Agents
- Source: https://arxiv.org/abs/2605.11363
- Title: PresentAgent-2: Towards Generalist Multimodal Presentation Agents

## Evidence

> PresentAgent-2 first summarizes the query into a focused topic and performs deep research over presentation-friendly sources to collect multimodal resources, including relevant text, images, GIFs, and videos.
>
> It then constructs presentation slides, generates mode-specific scripts, and composes slides, audio, and dynamic media into a complete presentation video.
>
> PresentAgent-2 supports three independent presentation modes within a unified framework: Single Presentation, Discussion, and Interaction.
>
> To evaluate these capabilities, we build a multimodal presentation benchmark covering single presentation, discussion, and interaction scenarios, with task-specific evaluation criteria for content quality, media relevance, dynamic media use, dialogue naturalness, and interaction grounding.
