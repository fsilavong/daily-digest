# HAGE: Harnessing Agentic Memory via RL-Driven Weighted Graph Evolution
- Source: https://arxiv.org/abs/2605.09942
- Title: HAGE: Harnessing Agentic Memory via RL-Driven Weighted Graph Evolution

## Evidence

> We propose HAGE, a weighted multi-relational memory framework that reconceptualizes retrieval as sequential, query-conditioned traversal over a unified relational memory graph.
>
> Given a query, an LLM-based classifier identifies the relational intent, and a routing network dynamically modulates the corresponding dimensions of the edge embedding.
>
> This allows memory traversal to prioritize high-utility relational paths while softly suppressing noisy or weakly relevant connections.
>
> Empirical results demonstrate improved long-horizon reasoning accuracy and a favorable accuracy-efficiency trade-off compared to state-of-the-art agentic memory systems.
