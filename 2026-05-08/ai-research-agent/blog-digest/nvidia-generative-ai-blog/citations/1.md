# Model Quantization: Post-Training Quantization Using NVIDIA Model Optimizer

- Source: https://developer.nvidia.com/blog/model-quantization-post-training-quantization-using-nvidia-model-optimizer/
- Title: Model Quantization: Post-Training Quantization Using NVIDIA Model Optimizer
- Retrieved text: The post describes post-training quantization (PTQ) using NVIDIA Model Optimizer (ModelOpt) on CLIP, including calibration on a representative dataset, fake quantization, and explicit handling for CLIP attention because the default module walker does not intercept the functional SDPA call. It reports comparable quality for CLIP-FP8 versus FP16 on CIFAR-100, ImageNet-1k, and MS-COCO Captions, and notes that real speed and memory gains require deployment export such as TensorRT.

## Evidence

> The worked example uses NVIDIA Model Optimizer (ModelOpt) to quantize CLIP to FP8 via post-training quantization, with calibration on a representative dataset and fake quantization before deployment.

> The article reports comparable quality for the quantized CLIP-FP8 model versus the FP16 baseline on CIFAR-100, ImageNet-1k, and MS-COCO Captions.

> CLIP attention needs explicit handling because ModelOpt’s default module walker does not intercept the functional SDPA call; the post says it registers a quantized replacement for `CLIPAttention` so attention is included in quantization.

> PTQ is only fake quantization during calibration and evaluation; actual speed and memory gains require exporting to deployment frameworks such as TensorRT.
