# Mistral News Digest

## Remote agents in Vibe. Powered by Mistral Medium 3.5.

- Mistral’s headline claim is a shift from laptop-bound coding agents to cloud-hosted remote agents that run in parallel and notify the user when finished, launched from Vibe CLI or directly in Le Chat. The same post frames this as the basis for a new Work mode in Le Chat for multi-step tasks [1](./citations/1.md).
- The underlying model is Mistral Medium 3.5, described as a public-preview flagship merged model with instruction-following, reasoning, and coding in one dense 128B weight set, a 256k context window, and configurable reasoning effort per request. Mistral says it can be self-hosted on as few as four GPUs and that its vision encoder was trained from scratch for variable image sizes and aspect ratios [1](./citations/1.md).
- Reported benchmark claims include 77.6% on SWE-Bench Verified, ahead of Devstral 2 and models like Qwen3.5 397B A17B, plus 91.4 on τ³-Telecom. The post also says the model was built for long-horizon tool use and structured output that downstream code can consume [1](./citations/1.md).
- For product behavior, remote Vibe sessions can be spawned from CLI or Le Chat, a local CLI session can be “teleported” to the cloud with session history/task state/approvals preserved, and sessions run in isolated sandboxes. The agent can inspect diffs, tool calls, progress states, and questions while running, and can open a GitHub pull request when done [1](./citations/1.md).
- The post also says Vibe plugs into GitHub, Linear, Jira, Sentry, Slack, and Teams, and is aimed at high-volume defined work such as refactors, test generation, dependency upgrades, CI investigations, and bug fixes. Mistral positions it as letting developers run several tasks in parallel without being the bottleneck on each step [1](./citations/1.md).
- Work mode in Le Chat (preview) is described as an agentic backend that can read/write, use several tools at once, and persist longer than a typical chat reply. Example use cases are cross-tool workflows, research and synthesis, inbox triage, Jira issue creation, and Slack summaries; connectors are on by default and sensitive actions require explicit approval [1](./citations/1.md).
- Availability and pricing details: Mistral Medium 3.5 is available in Mistral Vibe and Le Chat on Pro, Team, and Enterprise plans; API pricing is $1.5 per million input tokens and $7.5 per million output tokens; open weights are on Hugging Face under a modified MIT license. It is also available on NVIDIA build endpoints and NIM for prototyping and deployment [1](./citations/1.md).
